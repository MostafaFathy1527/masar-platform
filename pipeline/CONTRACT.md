# Content pipeline — generation contract

Rules for generating lesson content in this repository. They exist because the same
mistakes recur, and because a generator that is trusted rather than checked produces work
nobody can defend.

## The order that matters

The gates were built **before** the generation. `validate.py`, `concept_log.py` and
`qa_gate.py` all existed, ran in CI, and had negative tests proving they refuse things,
before a single lesson was generated by this pipeline.

That ordering is the argument. A generator built first and gated later is gated to
whatever it already produces; gates built first define what is acceptable independently of
what any model happens to emit.

## What the pipeline may and may not do

**May:** draft lesson JSON and item JSON from a source note, at a requested level.

**May not:**
- **Publish.** Output arrives as `status: DRAFT`. A human clicks publish. This is a
  permission boundary, not a convention.
- **Invent facts about insurance practice.** If a claim is not in the source note, it goes
  to `needs-verification.md` for a human to confirm or cut. A plausible sentence nobody
  can source is the most expensive kind of output.
- **Read anything outside `pipeline/sources/`.** No client material, no employer material,
  no scraping.
- **Edit a previous output in place.** Copy to `vN+1`. If a human hand-edited an output,
  **their version is the new baseline** and regeneration diffs onto it.

## Hard content rules

1. **No real licensed code sets.** No CPT, HCPCS, CDT, DRG, or X12 remark and adjustment
   code shapes. Every code is a fictional training code: `PRC-1000` family for procedures,
   `DX-A100` for diagnoses. `validate.py` enforces this and an occurrence is an automatic
   rubric 1.
2. **No employer or client names**, ever, in any form. The denylist is untracked and
   passed to `validate.py --denylist`.
3. **Fictional payers, clinics, patients and amounts**, labelled as training data.
4. **Every option carries feedback naming the misconception it represents.** A distractor
   without one is a QA failure, not a stylistic preference.
5. **≤180 words of prose between two acting blocks at L2+.** Checked mechanically.
6. **Arabic is not optional on a lesson that claims to be bilingual.** If a lesson ships
   English-only, set `bilingual: false` — the player then says so on the page. Pasting
   English into Arabic fields while claiming Arabic is caught by both gates.

## The loop

```
source note  →  generate  →  validate.py  →  concept_log.py  →  judge  →  qa_gate.py
                    ↑                                                          │
                    └──────────── one retry with the report appended ──────────┘
                                                                    then stop for a human
```

Each gate is a hard fail. They are ordered cheapest-first on purpose: there is no point
paying for a judgement on a document that does not parse.

## Known failure modes

Recorded because they recur, and because a pipeline that does not write these down repeats
them:

- **Definition drift.** A later lesson re-explains a concept an earlier one taught. The
  learner assumes they missed something. `concept_log.py` refuses it.
- **Forward reference.** A lesson leans on a term introduced later. Same check.
- **Cards that are lists.** A "visual card" containing three bullets is a list wearing a
  border. Rubric criterion 2.
- **Distractors nobody would pick.** They make an item easier while looking thorough.
  Rubric criterion 4.
- **Feedback that restates the stem.** "Correct, because this is the correct answer."
  Rubric criterion 4.
- **Confident invention.** Fluent, plausible, unsourced. Goes to `needs-verification.md`.
- **Position bias.** Authoring the correct option first in every item. Found in this
  project by playing the bank adversarially: "always answer A" scored 89%. Options are
  shuffled per attempt at serve time, so authored order is not load-bearing — but do not
  rely on that to excuse a keyed bank.

## Files

```
pipeline/
  the project rules file              this contract
  rubric.md              8 criteria, the thresholds, and what the score is worth
  prompts/               generate · revise · judge
  sources/               the only permitted input
  memory/
    concept-log.json     what has been taught, and where
    run-log.jsonl        every run, including failures
  validate.py            structure, semantics, forbidden content
  concept_log.py         re-definition and forward-reference checks
  qa_gate.py             applies the rubric thresholds, writes the report
  test_*.py              negative tests for each gate
```
