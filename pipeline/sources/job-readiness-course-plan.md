# Course plan — Ready for work (الاستعداد لسوق العمل)

Not a source note: the plan the source notes in this directory follow. The pipeline does not
read this file.

**Audience.** Young Arabic speakers looking for, or starting, their first job, many of them
with intermittent or no internet: schools, youth centres, training programmes, camps. The
course is meant to be packaged for offline use (a static build, then a ZIM file for Kiwix).

**Language.** Arabic first, in Modern Standard Arabic so it reads the same in every Arab
country; English as a full mirror. No dialect in the Arabic fields.

**Honesty label, on every lesson.** Drafted from the author's source note by an AI pipeline,
scored by a panel of model judges, and reviewed and edited by an instructional designer
before publication. Not career, legal or financial advice.

**Rules every note follows.** Public, general knowledge only. No statistics, no salary
figures, no named companies, laws or countries' rules (they differ, and a learner offline
cannot check them). Practices that hold almost everywhere, stated as practices, with the
reason behind each one.

not passed is not in the offline package.
