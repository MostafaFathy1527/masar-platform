# Masār quality gates

The content pipeline behind [masar.mostafafathy.com](https://masar.mostafafathy.com) refuses to
publish any lesson until it passes four gates. This Space runs the three that need no model in
your browser (Python on Pyodide, no server) on the real lesson files from the repository, or on
anything you paste. The fourth, the judge panel, runs on hosted and rented models, outside the
Space.

- **Validator** — structure (JSON Schema generated from the renderer's Zod schema), semantics,
  and forbidden content.
- **Concept log** — no lesson may re-introduce a concept an earlier lesson taught, or use one
  before it is taught.
- **Rubric gate** — thresholds applied to a fresh-context judge's verdict; which criteria apply
  is derived from the lesson, never from the judge.

No model is called here. Source, tests and the public record of twenty things that looked
right and weren't: [github.com/MostafaFathy1527/masar-platform](https://github.com/MostafaFathy1527/masar-platform).

This folder is a flat snapshot produced by `python demo/hf-space/sync.py` from the repository root; the `sample__*` files are copies of the authored course lessons and the pipeline drafts. `index.html` is generated by `build_static.py` and inlines every file the gates read; `gates_core.py` holds the logic shared by the page and by `app.py` (a Gradio front end for running the same thing locally with `pip install -r requirements.txt && python app.py`).
