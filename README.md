# Masār (مسار)

A practice-first learning platform: a lesson can be published at three defined depths,
assessment is built from a blueprint rather than a pile of questions, and the AI pipeline
that produces the lessons ships in this repo with its QA gate.

**Self-initiated portfolio project.** Not a commercial product: payments run in
sandbox/test mode only, all demo data is synthetic and labelled as such, and the course
content is original, written from public knowledge. Not affiliated with or recognized by
any certification body. Not billing, clinical, legal or regulatory advice.
